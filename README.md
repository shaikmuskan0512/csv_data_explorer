
# 📊 CSV Data Explorer

CSV Data Explorer is an interactive web application built with **Python, Pandas, and Streamlit** for exploring, cleaning, and preprocessing CSV datasets.

The application allows users to upload a CSV file and quickly understand the dataset, identify missing values, perform basic data cleaning and manipulation, and view useful statistics through an easy-to-use interface.

## 🚀 Features

- 📁 Upload CSV files
- 📊 View dataset rows and columns
- 🔍 Explore dataset information
- 🧾 View column data types
- 📈 Generate basic statistical summaries
- ❌ Identify missing values
- 🧹 Handle missing values
- 🔄 Perform basic data transformations
- 🛠️ Perform data manipulation and preprocessing
- 📋 Preview cleaned data
- 🌐 Interactive Streamlit interface

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **Streamlit**
